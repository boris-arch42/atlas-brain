# Manager Playbook — Core V1 & certification

## 🎯 Objectif
Standardiser le management ENT via un **playbook Core V1** (routines quotidien/hebdo : réunions, CR + décisions, Slack, sécurité) dont **l'adoption est le livrable** — mesurée par certification et scorecard. **V2** (second brain IA, intégrations Work, lifecycle manager) après ancrage V1.

## 🧱 Dispositif
- **Certification manager** : quiz dans Work (questions spécifiques entreprise), passage « live », intégré à l'onboarding.
- **Scorecard trimestrielle** par manager.
- **4 KPI** : % CR au standard · réunions < 45 min / < 5 personnes · % managers certifiés · discipline Slack.
- **Base de décisions** (Kanban) avec délais décision → rediscussion / implémentation.
- **Zéro nouvelle licence** : transcriptions internes, **Tella** (vidéo), Slack, Keeper.
- **Work = source unique** + dashboard global (avec [[Anisse Rbibe]]).

- Communs : templates, process CR, intégration Slack. Points récurrents : **mercredi 16h (à confirmer)** + notes async Slack.
