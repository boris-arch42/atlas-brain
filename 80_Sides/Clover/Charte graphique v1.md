## Typographie
- **Titres / display : Lora** (serif) — chaleur, confiance, citations
- **Texte / interface : Work Sans** (sans humaniste) — corps, boutons, libellés UI
- **Données / mono : JetBrains Mono** — chiffres, tarifs, identifiants, dashboards
- Échelle : H1 Lora 28 · H2 Lora 18 · H3 Work Sans 12 · Body Work Sans 10/15 · Data Mono 9
- *Distinct de Riven (Fraunces + Inter + IBM Plex Mono).*

## Marque — symbole provisoire (arche)
- Arche pleine (seuil / accueil / abri) + point keystone. Variantes : primaire (Jade), mono (Encre/blanc), réservé (Pousse sur Sapin).
- Zone de respiration = demi-largeur du symbole. Ne pas déformer, recolorer hors palette, ajouter contour/ombre.
- *Symbole de travail à confirmer/affiner avec un designer une fois le nom choisi.*

## Règles d'usage rapides
- Boutons : primaire = Jade · action forte = Argile (un seul CTA/écran) · secondaire = contour Jade.
- Accessibilité : texte Sapin/Encre sur Coquille/Rosée/Sable = AA OK. Argile en aplat + texte blanc ; éviter Argile en petit texte sur fond clair.
