## Points process clarifiés en live

### Sur le sourcing
- Aikho fait du **sourcing actif (chasse)** sur LinkedIn et job boards, pas seulement de la collecte passive
- Double flux : sourcing chassé + candidatures directes via le lien d'annonce
- Les candidats reçoivent l'invitation par mail (pas LinkedIn direct)

### Sur l'interview IA
- Trame de base commune mais adaptation dynamique selon le profil et les réponses
- Switch de langue automatique en cours d'interview pour tester les compétences (ex: passage en anglais si requis)
- **Filtre anti-IA intégré** : détection de lecture de texte, assistance externe, usage de ChatGPT
- Analyse non-verbale via vidéo (pas de mode audio seul)
- Score de satisfaction candidat très bon en pratique (référence David Thomas : 4.85/5 sur 600 recrutements/an)

### Sur les exercices techniques
Question d'Océane qui a permis un cadrage important par Alec :
- Les exercices viennent **après** l'interview IA, sur le top 3% des candidats
- Process type : envoi via la fonction email d'Aikho avec Loom d'instructions + lien formulaire
- Automation analyse du résultat via Claude/IA + report dans les notes du candidat dans Aikho
- Standardisation à 100% pour les recrutements récurrents (expert, coach, intégrateur, sales, SDR)

### Sur les seuils de complétude
- À partir de **40%**, les interviews sont déjà très précises
- 100% est contre-productif (filtres trop restrictifs, peu de candidats)
- Recommandation : remplir l'essentiel et lancer

### Sur les bans
Deux niveaux : ban annonce (limité à un poste) et ban entreprise (toutes offres entrepreneurs.com). Géré manuellement par les heads.

### Sur les notifications
"Keep me posted" configurable par sous-agent (sourceur / reviewer / interviewer / manager). Granularité à choisir par head selon préférence.
